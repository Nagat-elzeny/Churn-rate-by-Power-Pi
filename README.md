# 📊 Telecom Churn Analytics Dashboard (Power BI / Data Analyst Portfolio)

## ✅ Overview
This project analyzes **customer churn** in a telecom dataset and visualizes key drivers of churn through an interactive dashboard.

The dashboard highlights:
- **Overall churn rate & churn counts**
- **Churn patterns by demographics (age, senior/under-30)**
- **Churn by account age & contract type**
- **Churn by payment method**
- **Churn reasons (top churn drivers)**
- **Churn by geography (map visualization)**
- **Effects of extra charges & unlimited plans**

---

## 🎯 Key Insights (Highlights)
- **Churn Rate:** ~**26.86%**
- **Total Customers:** ~**6.87K**
- **Total Churned:** ~**2K**
- Top churn reasons include issues like:
  - **Competitor offers**
  - **Dissatisfaction / service problems**
  - **Network reliability & price concerns**
  - **Support/attitude problems**

## 🧠 Dashboard Pages (What’s Included)
1. **Overview Churn Rate**
   - KPI summary cards (Churn rate, customer count, churned count)
   - Churn reasons bar chart
  
   - ![image alt](https://github.com/Nagat-elzeny/Churn-rate-by-Power-Pi/blob/main/Overveiw.PNG?raw=true)

2. **Churn Demographics**
   - Senior vs Under 30 churn comparison
   - Overall churn KPIs

3. **Age Groups**
   - Number of customers vs churn rate by age bins

4. **Contract Type**
   - Churn rate trends vs account length
   - Contract category comparison

5. **Payment and Contract**
   - Churn relation with payment method and contract type

6. **Extra Charges**
   - Churn rate by:
     - Unlimited data plan (Yes/No)
     - Grouped consumption (Less than 5 GB, 5–10 GB, 10+ GB)

7. **International Calls**
   - Churn by state with a geographic scatter/map

8. **Groups and Categories**
   - Churn by category + customer distribution visuals

## 🗂️ Dataset
- Telecom customer churn dataset (CSV / Excel)
- Includes fields such as:
  - `CustomerID`, `Churned`

  - Contract details (monthly/yearly/two year)
  - Payment method
  - Customer support calls

  - Service dissatisfaction indicators
  - Extra charges & consumption groups
